# WhatsApp setup

The current build does not send messages. For a future adapter, configure an approved WhatsApp Business Platform sender and template in Meta, then store `WHATSAPP_ACCESS_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_RECIPIENT_NUMBER`, `WHATSAPP_TEMPLATE_NAME`, and `WHATSAPP_TEMPLATE_LANGUAGE` as backend secrets. Observe applicable template and opt-in rules. Do not include bill attachments or unnecessary personal information. An adapter, retries, and delivery-status auditing are still required.
